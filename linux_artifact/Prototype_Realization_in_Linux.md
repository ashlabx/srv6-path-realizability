# Prototype Realization in Linux (paper-ready note)

We implemented a minimal Linux namespace-based realization of both a VXLAN baseline and an SRv6 steered forwarding model on a small Clos-style topology with two leaf nodes, two spine nodes, four end hosts, and one service node. The realization uses standard Linux networking primitives, including network namespaces, veth pairs, VXLAN interfaces, IPv6 routing, and SRv6 local processing via `seg6local` behaviors. The purpose of the artifact is not to serve as a primary performance evaluation, but to validate that the substrate comparison studied in the paper is not purely conceptual. In particular, the artifact demonstrates that (i) the VXLAN baseline can be realized with underlay reachability and static VTEP configuration, (ii) SRv6 steering can be realized through explicit segment lists and local SID processing, and (iii) service-path intent can be expressed differently across the two substrates in an executable Linux environment. We treat this prototype as a realizability check and not as a substitute for the flow-level simulation or as evidence of production dataplane performance.
